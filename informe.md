
El proyecto fue desarrollado con el propósito de aplicar los principios fundamentales de Programación Orientada a Objetos mediante una solución teórica y una solución funcional, siendo la solución teórica una landing page educativa sobre POO en Java, mientras que la solución funcional corresponde a un sistema de parqueadero desarrollado en el mismo Java.

# Estructura General del Proyecto

El proyecto fue dividido en dos subproyectos:

## Landing Page

Aplicación frontend desarrollada con:

- HTML
- CSS
- JavaScript

## Sistema Funcional

Aplicación Java orientada a objetos desarrollada mediante:

- clases
- herencia
- encapsulamiento
- polimorfismo
- excepciones
- buenas prácticas

# Lenguajes y otras utilidades:

## Frontend

- HTML5
- CSS3
- JavaScript
- TailwindCSS

## Consola

- Java
- Scanner
- HashMap
- Excepciones

## Herramientas

- GitHub
- VS Code

# Metodología

El proyecto fue desarrollado utilizando separación de responsabilidades:
- docs-project : documentación
- poo-project : contenido educativo
- funcional-project : aplicación funcional

# Conclusiones
El proyecto permitió aplicar correctamente los conceptos fundamentales de POO mediante una aplicación educativa y una aplicación funcional en Java, las cuales al desarrollarse en el orden escrito, tras de ir muy bien de la mano, refrescaron conocimiento adquirido en el trascurso del semestre, en otras palabras, el proyecto funcional fué una mini práctica de la teoría explicada en nuestro landing page.
